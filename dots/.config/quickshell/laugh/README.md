# laugh

Quickshell shell used by [Laughdots](../../../../README.md).

This is a vendored, renamed copy of [end4-pC](https://github.com/pctrade/end4-pC)
by pctrade, itself a fork of [end-4's illogical-impulse](https://github.com/end-4/dots-hyprland).
It is licensed under GPL-3.0; see `LICENSE` in this directory.

Nothing is fetched from those repositories at install or run time. The shell is
installed by laughdots' `./setup install` into `~/.config/quickshell/laugh` and
started with `qs -c laugh`.
